## 项目概览学习

- 阅读 `CLAUDE.md`、`docs/architecture.md`、`docs/product.md`，浏览 `packages/` 各子包结构
- ChisaCode 是本地优先的 AI 编码 Agent 监控/控制系统，npm workspace monorepo
- 核心分层：客户端层（Mobile/CLI/Desktop）→ Daemon（Node.js，WebSocket API + MCP + 文件持久化）→ Agent 提供商（Claude/Codex/OpenCode/MiMoCode/Pi/Kimi/ACP）
- 持久化路径：`$CHISACODE_HOME/agents/` 下 JSON 文件
- 关键约束：协议向后兼容、不要本地跑全套测试、改完跑 typecheck+lint、用 npm scripts 而非直接 npx
- 为用户生成了一张架构总览可视化图
