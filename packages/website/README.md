# @chisacode/website

Marketing site for ChisaCode — [chisacode.sh](https://chisacode.sh).

Built with Vite, TanStack Router/Start, and Cloudflare Pages.

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Typecheck

```bash
npm run typecheck
```

## Test

```bash
npm run test
```

## Deploy

```bash
npm run deploy
```
