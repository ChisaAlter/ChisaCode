3 · 附着缝（attached）—— 横幅与输入框视觉融合

横幅只保留顶部圆角/边框，输入框只保留底部圆角/边框，中间无缝无线——两者拼成一张连续表面（红色箭头处无分界线）。 玻璃态仅 web/Electron（backdrop-blur），native 平铺同 tint 底色。

4 · 优先级堆叠 —— 交互演示

优先级：activity（spinner）＞ error / warning ＞ notice / info。最高项附着展示，其余折叠进 peek 标签（hover 展开、点击 pin 住、Esc 收起）。 关闭按「会话 + 消息」记忆——同一条错误不再出现，不同错误照常出现。

+ 附件Grok-4.5 · 高

5 · 动画与行为规格

实现时以此为准（Unistyles + 220ms cubic-bezier(0.2, 0, 0, 1)）：

进入（新横幅注入）opacity 0→1 + translateY(-6px→0)，220ms
关闭（dismiss）opacity 1→0 + translateY(0→-4px)，220ms 后卸载；同级下一项顶上附着
peek 展开 / 收起max-height + opacity 过渡 220ms；web hover 展开、native 点击；Esc 收起并取消 pin
关闭记忆模块级 Set<threadKey:message>——重挂载保留；同 key 不再现，不同 message 再现
迁移目标发送错误文本 → error 横幅；agent 面板 agent-error 分支 → 堆叠（history-sync 分支保留原位）
